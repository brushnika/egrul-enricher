# 🏢 Обогащение данных из ЕГРЮЛ

Скрипт для дополнения данных о компаниях из ЕГРЮЛ: ИНН, ОГРН, руководитель.

## 📋 Что делает

- Берёт Excel-файл с компаниями
- Ищет каждую компанию в ЕГРЮЛ
- Извлекает: ИНН, ОГРН, ФИО руководителя, должность
- Сохраняет результат в новый Excel-файл

## 🛠️ Технологии

- **Python 3**
- **Selenium** — автоматизация браузера
- **requests** — HTTP-запросы
- **free-proxy** — автоматическая смена прокси
- **openpyxl** — работа с Excel
- **webdriver-manager** — автоустановка драйвера Chrome

## ⚙️ Как работает

1. Загружает Excel-файл с компаниями
2. Для каждой компании открывает ЕГРЮЛ
3. Вводит название в поиск (посимвольно, как человек)
4. Извлекает данные: ИНН, ОГРН, ФИО руководителя
5. Сохраняет результат в новый Excel-файл

## ✨ Особенности

- **Автоматическая смена прокси** — обход блокировок по IP
- **Имитация человека**: паузы, посимвольный ввод, случайные User-Agent
- **Промежуточное сохранение** каждые 3 компании — данные не потеряются
- **Обработка ошибок** и прерываний (`Ctrl+C`)

## 📦 Установка


```bash
pip install selenium webdriver-manager openpyxl requests free-proxy
```
## 🚀 Запуск

1) Открой egrul_enricher.py

2) Измени настройки:
```bash
INPUT_EXCEL_PATH = "companies.xlsx"  # путь к исходному Excel
USE_PROXY = True                     # использовать ли прокси
PAUSE_MIN = 8.0                      # мин. пауза между запросами
PAUSE_MAX = 15.0                     # макс. пауза
```
4) Запусти:
```bash
python egrul_enricher.py
```
